# 宇宙物理天体アライメント診断 (COSMO_ALIGNER v1.0)

> **観測対象者のお名前と基準時間軸（生年月日）から、宇宙定数同調率や調和数字を算出するSF風天体占いシミュレーター**

観測対象者（お名前）と基準時間軸の起点（生年月日）を入力することで、天体位置や重力干渉のシミュレーションを行い、今日の「宇宙定数同調率」や「調和数字（6選）」、脳のエントロピーを整える「重力特異点アクション」を解析・出力するブラウザ完結型のWebツールです。

---

## 🌟 主な特徴

- 🔒 **安心・安全の完全ローカル処理**: 入力データや診断処理が外部サーバーへ送信されることは一切ありません。お使いのブラウザ内部でハッシュ値化して解析を行います。
- 🪐 **宇宙物理・SF風パラメーター**: 潮汐力干渉値、重力波共鳴周波数、ダークエネルギー親和性など、潜在的な状態値を算出。
- 🔢 **調和数字（6選）の算出**: 今日の天体配置アライメントに基づいて調和された、1〜43（ロト6などに対応）の6つの数字を出力。
- 💡 **重力特異点アクション**: 日常のPC作業や生活の中で局所的エントロピーを整え、思考をリフレッシュするためのユニークなSF風アドバイスを提示。
- 📅 **日次決定論的シード計算**: 今日中なら何度実行しても同一の結果が得られ、日付が変わると天体軌道アライメントが更新されます。

---

## 🚀 使い方・ご利用手順

1. **ツールの起動**:
   - `index.html` をダブルクリックして、Google Chrome、Microsoft Edge、Safari などのブラウザで開きます。
2. **情報の入力**:
   - 観測対象コード（お名前またはニックネーム）を入力します。
   - 基準時間軸の起点（生年月日）を選択します。
3. **シミュレーション実行**:
   - 「重力場シミュレーションを実行」ボタンをクリックします。
4. **結果の確認**:
   - 宇宙定数同調率、各種干渉値、調和数字（6選）、重力特異点アクションが表示されます。
